# SetTFNetwork

SetTFNetwork

## Usage

``` r
SetTFNetwork(seurat_obj, tf_net, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- tf_net:

  dataframe storing the TF network info in ConstructTFNetwork

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
