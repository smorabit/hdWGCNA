# SetRegulonScores

SetRegulonScores

## Usage

``` r
SetRegulonScores(seurat_obj, regulon_scores, target_type, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- regulon_scores:

  dataframe storing the TF regulon scores

- target_type:

  dataframe storing the TF regulon scores

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
