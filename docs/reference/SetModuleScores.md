# SetModuleScores

SetModuleScores

## Usage

``` r
SetModuleScores(seurat_obj, mod_scores, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- mod_scores:

  dataframe storing the module expression scores

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
