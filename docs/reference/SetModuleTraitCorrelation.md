# SetModuleTraitCorrelation

SetModuleTraitCorrelation

## Usage

``` r
SetModuleTraitCorrelation(seurat_obj, mt_cor, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- mt_cor:

  matrix of module-trait correlation results

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
