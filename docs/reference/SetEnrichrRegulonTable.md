# SetEnrichRegulonTable

SetEnrichRegulonTable

## Usage

``` r
SetEnrichrRegulonTable(seurat_obj, enrich_table, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- enrich_table:

  dataframe storing the results of running enrichr

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
