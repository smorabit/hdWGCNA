# SetAvgModuleExpr

SetAvgModuleExpr

## Usage

``` r
SetAvgModuleExpr(seurat_obj, avg_mods, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- avg_mods:

  dataframe storing the average expression of all genes in the same
  module

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
