# SetMotifOverlap

SetMotifOverlap

## Usage

``` r
SetMotifOverlap(seurat_obj, overlap_df, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- overlap_df:

  dataframe containing motif-module overlap info

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
