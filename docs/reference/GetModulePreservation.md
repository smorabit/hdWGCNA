# GetModulePreservation

GetModulePreservation

## Usage

``` r
GetModulePreservation(seurat_obj, mod_name, wgcna_name = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object

- mod_name:

  name of the module preservation test to store

- wgcna_name:

  The name of the hdWGCNA experiment in the seurat_obj@misc slot
